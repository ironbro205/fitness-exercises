# 1. 확장성(Scalability) 첫걸음 (2026-08-20)

- 확장성 = 사용자가 늘어도 서비스가 버티게 키우는 능력 (김밥집 비유)
- 수직 확장(vertical): 서버 1대를 더 강력하게 — 간단하지만 한계 있음
- 수평 확장(horizontal): 서버 여러 대로 분산 — 대형 서비스의 기본, 대신 새 숙제 생김
- 캐싱(caching): 자주 쓰는 결과를 미리 만들어 둠 — 서버는 덜 일하고 응답은 빨라짐
- 로드밸런싱(load balancing): 요청을 여러 서버에 골고루 분배
- 복제(replication): 같은 데이터를 여러 곳에 — 사고 대비 + 읽기 분산
- 파티셔닝(partitioning): 커진 데이터를 나눠 보관 — 용량 한계 극복
- 핵심 문장: "모든 것은 트레이드오프(trade-off)다"
